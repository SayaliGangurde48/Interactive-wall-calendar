# 📅 Interactive Wall Calendar

A modern, responsive **wall calendar UI** built using React (Vite) that allows users to select date ranges and add notes.

---

## 🚀 Features

* 📆 **Wall Calendar UI** inspired by real-life calendar design
* 📅 **Date Range Selection** (Start → End)
* 📝 **Notes Section** for selected dates
* 📱 **Fully Responsive Design** (Mobile + Desktop)
* ⚡ Smooth and interactive UI

---

## 🛠 Tech Stack

* React (Vite)
* TypeScript
* Tailwind CSS
* date-fns
* Framer Motion (for animations)

---

## ▶️ How to Run Locally

### 1. Clone the repository

```
git clone https://github.com/SayaliGangurde48/Interactive-wall-calendar.git
```

### 2. Open the project

```
cd wall-calendar-standalone
code .
```

### 3. Install dependencies

```
npm install
```

### 4. Run the development server

```
npm run dev
```

### 5. Open in browser

Visit:

```
http://localhost:5173
```
